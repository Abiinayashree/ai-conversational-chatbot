# AI Conversational Chatbot

## Project Overview
Developed an AI-powered conversational chatbot using Python and Groq API. The chatbot generates dynamic AI responses for user queries using Large Language Models (LLMs).

## Technologies Used
- Python
- Groq API
- Llama 3.1 Model

## Key Features
- AI-generated conversational responses
- Continuous user interaction
- Prompt-based AI workflow
- Real-time response generation

## Concepts Learned
- API integration
- Conversational AI workflow
- Prompt-based interaction
- Large Language Model usage
- Dynamic response generation

## Project Workflow
1. User enters a query
2. Query is sent to Groq API
3. LLM processes the request
4. AI-generated response is displayed to the user
